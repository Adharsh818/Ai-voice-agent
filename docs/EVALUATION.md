## 6. Known gaps

- Simple-turn latency (T1) is above target: end-of-speech detection dominates; Deepgram's endpointing and the voice-gated end of turn were tuned on the owner's recordings to avoid cutting callers off, which costs time.
- Model turns answered by the fallback because the model was slower than `NLU_HEAD_DEADLINE_S` (phone calls through Asterisk: 63/84); the fallback path handles them, but replies are plainer. `tools/preflight.py` suggests a deadline for the day's model speed.
- Deepgram can mishear Indian names. Common first names are passed to it as hints (`config.DEEPGRAM_NAME_KEYTERMS`): in the 11 Oct replay the owner's name, heard as "Adesh" on 6 Oct, came out right in both recordings. A name outside the list can still be misheard, so Emma confirms names implicitly and reads numbers back.
